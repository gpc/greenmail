[[releaseNotes]]
== Release Notes

* 7.0.2 - Migrated to the `grails-plugin-template` build structure; guard against starting the
  GreenMail server twice when the application context is refreshed; the `MimeMessage` `tos` / `ccs` /
  `bccs` properties now return an empty list instead of `null` when the message has no recipient of
  that type, and `to` / `cc` / `bcc` return `null` instead of throwing a `NullPointerException`
* 7.0.1 - Package the precompiled GSP view so the `/greenmail` list renders in consuming applications
* 7.0.0 - Support for Grails 7, Jakarta Mail and GreenMail 2.x
* 5.0.0 - Support for Grails 5
* 2.0.0 - Support for Grails 3
* 1.3.0 - Support for Grails 2
